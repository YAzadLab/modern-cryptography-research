Question 1:
23 mod(7)

use the formula n = qm + R
n = original number in this case 23
m = the mod number in this case 7 
q = the number you get by dividing 23 and 7 without the remainder in this case 23/7 = 3R2 and use 3
R = the remainder

(23) = (3)(7) + 2
hence: 23 mod(7) = 2
